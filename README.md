# Bioinformatics-Sequence-Analyzer
A beginner bioinformatics sequence analysis tool built from scratch in Python.
To be accessed through "main.py"

=> Features (DNA and RNA Toolkit)

Sequence Validation, Complementary Strands, Reverse Strands and their complementary ones, Transcription, AT/GC/AU Count, Total Base Counter and Molecular Weight Calculator. 
=> Features (Protein Toolkit)

Validation, Sequence Length, Amino Acid Counter/Frequency/Composition, Molecular weight, Polarity, Acidic/Basic Nature identifier, Aromatic AA Identifier, Conversion of AA to Three letter/Full name.
=> Features (FASTA Toolkit)

File reader, Header/Sequence Display,Sequence Length and Validation.
