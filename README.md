# 🧬 Bioinformatics Sequence Analyzer

A beginner-friendly **bioinformatics sequence analysis tool** built from scratch in Python.

The project provides separate toolkits for **DNA, RNA, proteins, and FASTA files**, accessible through `main.py`.

---

## 🧪 Features

### 🧬 DNA & RNA Toolkit

* **Sequence Validation**
* **Complementary Strand**
* **Reverse Strand**
* **Reverse Complement**
* **Transcription**
* **AT / GC / AU Content**
* **Total Base Counter**
* **Molecular Weight Calculator**

### 🧫 Protein Toolkit

* **Sequence Validation**
* **Sequence Length**
* **Amino Acid Counter**
* **Amino Acid Frequency / Composition**
* **Molecular Weight Calculator**
* **Polarity Identification**
* **Acidic / Basic Nature Identification**
* **Aromatic Amino Acid Identification**
* **Amino Acid Conversion**

  * One-letter → Three-letter code
  * One-letter → Full amino acid name

### 📄 FASTA Toolkit

* **FASTA File Reader**
* **Header Display**
* **Sequence Display**
* **Sequence Length**
* **Sequence Validation**

---

## 🚀 Usage

Run the main program through:

python main.py
